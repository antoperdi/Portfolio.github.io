I. PENAMAAN KELAS & ID (HTML & CSS)
------------------------------------------------------------------------

II. PENAMAAN VARIABEL & FUNGSI JAVASCRIPT (script.js)
------------------------------------------------------------------------
1. Efek Mengetik Otomatis (Hero Section):
   - words : Array berisi string peran pekerjaan (misalnya: ['Web Developer', 'UI/UX Designer', 'Tech Enthusiast']).
   - wordIndex : Indeks penunjuk kata aktif dalam array.
   - charIndex : Indeks penunjuk karakter huruf aktif yang sedang diketik atau dihapus.
   - isDeleting : Boolean untuk menandai apakah teks sedang dalam proses dihapus.
   - typewriterElement : Variabel penampung elemen DOM `.typewriter`.
   - typeEffect() : Fungsi rekursif untuk menjalankan animasi ketik, hapus, jeda, dan transisi antar kata.

2. Navigasi Link Aktif & Animasi Stagger Tabel & Progress Skill (Scroll Observer):
   - sections : NodeList penampung semua elemen `<section>` di halaman.
   - navLinks : NodeList penampung seluruh tautan navigasi di navbar.
   - skillRows : NodeList penampung semua baris tr dalam tabel keahlian untuk animasi.
   - skillProgressBars : NodeList penampung seluruh elemen bar kemajuan skill_progress.
   - observerOptions : Objek konfigurasi Intersection Observer (threshold, rootMargin).
   - navObserver : Instansi IntersectionObserver untuk melacak section aktif di viewport.
   - skillsObserver : Instansi IntersectionObserver untuk memicu animasi baris tabel keahlian secara berurutan (stagger) dan pengisian lebar progress bar saat terlihat.
   - (Callback Observer) : Memperbarui class active di navbar, menambahkan class animate di tabel row, dan mengisi lebar style.width progress bar.

3. Mobile Menu Toggle:
   - menuToggle : Variabel penampung elemen DOM `.menu-toggle`.
   - navLinksContainer : Variabel penampung elemen DOM `.nav-links`.
   - (Event Listener) : Menangani klik menuToggle untuk menambah/menghapus kelas `.show` pada navLinksContainer untuk membuka menu responsif di layar kecil.

4. Filter Galeri Portofolio:
   - filterButtons : NodeList penampung tombol filter kategori `.filter-btn`.
   - portfolioCards : NodeList penampung elemen kartu proyek `.portfolio-card`.
   - filterProjects(category) : Fungsi untuk menyembunyikan atau menampilkan kartu proyek dengan menambahkan kelas CSS `.hide` atau `.show` berdasarkan parameter kategori yang dipilih.

5. Galeri Modal (Lightbox):
   - galleryItems : NodeList penampung gambar galeri `.gallery-img`.
   - modalOverlay : Elemen DOM overlay modal `.modal-overlay`.
   - modalImg : Elemen DOM gambar di dalam modal `.modal-img`.
   - modalClose : Elemen DOM tombol tutup `.modal-close`.
   - openModal(src) : Fungsi untuk mengaktifkan overlay modal dan menetapkan src gambar modal dengan src gambar yang di-klik.
   - closeModal() : Fungsi untuk menonaktifkan overlay modal dengan menghapus kelas aktif.

6. Formulir Kontak & Validasi:
   - contactForm : Elemen DOM formulir `.contact-form`.
   - (Event Listener Submit) : Menangkap event submit form, mencegah reload default, melakukan validasi dasar, menampilkan notifikasi sukses interaktif, dan mereset form.

7. Parsing Data Detail Proyek Dinamis (project-detail.html):
   - projectsData : Objek data besar statis berisi detail masing-masing proyek (warkop-qr, dashboard-finansial, portal-berita).
   - urlParams : Instansi URLSearchParams untuk menangkap query string di URL browser.
   - projectId : Nilai ID proyek aktif yang didapatkan dari parameter query 'project'.
   - errorContainer : Elemen DOM penampil notifikasi jika proyek tidak terdaftar.
   - detailContent : Elemen DOM kontainer utama detail proyek yang di-render dinamis.

IV. PENAMAAN BLOK KODE BACKEND ADMIN (LARAVEL 12)
------------------------------------------------------------------------
1. Model Pengguna (app/Models/User.php):
   - User : Kelas Model Eloquent untuk representasi tabel 'users'.
   - $table : Variabel penentu nama tabel di MySQL ('users').
   - $fillable : Variabel array kolom yang dapat ditulis ('username', 'password', 'name').
   - $hidden : Variabel array kolom yang disembunyikan dalam output ('password').
   - $timestamps : Variabel penentu pencatatan waktu otomatis (diatur ke false).
   - casts() : Fungsi mendapat casting tipe data (kolom password dikonversi ke hashed).

2. Controller Autentikasi (app/Http/Controllers/AuthController.php):
   - AuthController : Kelas Controller utama pengelola status masuk admin.
   - showLogin() : Fungsi untuk merender view form login admin ('admin.login') serta mengalihkan jika sudah aktif login.
   - login() : Fungsi untuk memvalidasi input username/password dari client secara asinkron (AJAX POST) dan memproses status masuk.
   - dashboard() : Fungsi untuk mengamankan dan menampilkan dashboard admin ('admin.dashboard').
   - logout() : Fungsi untuk menghapus session aktif, meregenerasi token CSRF, dan mengembalikan user ke halaman masuk.

3. Helper Global Kustom (app/Helpers/helpers.php):
   - html_escape() : Fungsi pembantu untuk menyaring input/output guna mencegah celah keamanan Cross-Site Scripting (XSS).
   - log_message() : Fungsi pembantu perekam log kesalahan sistem/keamanan secara eksternal ke log Laravel.

4. Database Seeder (database/seeders/AdminUserSeeder.php):
   - AdminUserSeeder : Kelas seeder database untuk akun admin awal.
   - run() : Fungsi utama pengisi baris data admin, melakukan hash password dengan bcrypt, dan menyimpannya ke tabel 'users'.

5. Model Profil Kustom (app/Models/Profile.php):
   - Profile : Kelas Model Eloquent representasi tabel 'profile' MySQL.
   - $table : Variabel penentu nama tabel di MySQL ('profile').
   - $fillable : Array kolom yang dapat ditulis ('name', 'title', 'bio', 'email', 'phone', 'address', 'profile_pic', 'hero_image_blob', 'hero_image_mime', 'about_image_blob', 'about_image_mime').
   - $timestamps : Dinonaktifkan (false) karena dikelola otomatis oleh trigger MySQL.

6. Controller Panel Admin (app/Http/Controllers/AdminController.php):
   - AdminController : Kelas Controller utama untuk panel pengelolaan dashboard admin.
   - index() : Fungsi penghitung statistik data dari MySQL dan penampil halaman utama dashboard admin ('admin.dashboard').
   - showUbahGambar() : Fungsi penampil halaman form "Ubah & Tambah Gambar" ('admin.ubah_gambar').
   - uploadGambar() : Fungsi pemroses unggahan gambar (maksimal 5MB) dan penyimpan data biner secara asinkron ke database MySQL.

7. Controller Portfolio Utama (app/Http/Controllers/PortfolioController.php):
   - PortfolioController : Kelas Controller utama penampil halaman beranda depan portfolio.
   - index() : Fungsi penarik seluruh data profil, keahlian, pendidikan, dan pengalaman dari database MySQL untuk dirender ke view 'portfolio.blade.php'.

8. Skema Kolom Tabel Database MySQL (Tabel: users & profile):
   - Tabel 'users' (Tabel Autentikasi Admin):
     * id : Kolom ID unik, tipe integer, Primary Key, Auto-increment.
     * username : Kolom username pengenal admin, tipe varchar(50), Unique Key.
     * password : Kolom penyimpanan password bcrypt hash, tipe varchar(255).
     * name : Kolom nama lengkap admin, tipe varchar(100).
     * created_at : Kolom penanda waktu pembuatan akun, tipe timestamp.
   - Tabel 'profile' (Tabel Data Portofolio Utama):
     * id : Kolom ID profil, tipe integer, Primary Key, Auto-increment.
     * name : Kolom nama lengkap pemilik portofolio, tipe varchar(100).
     * title : Kolom jabatan/profesi pekerjaan, tipe varchar(150).
     * bio : Kolom biografi ringkas profil, tipe text.
     * email : Kolom alamat e-mail aktif, tipe varchar(100).
     * phone : Kolom nomor kontak telepon genggam, tipe varchar(20).
     * address : Kolom alamat domisili lengkap, tipe text.
     * profile_pic : Kolom nama berkas gambar foto profil, tipe varchar(255).
     * updated_at : Kolom penanda pembaruan data otomatis, tipe timestamp.
     * hero_image_blob : Kolom penyimpanan data biner foto profil utama, tipe longblob.
     * hero_image_mime : Kolom tipe format berkas foto profil, tipe varchar(50).
     * about_image_blob : Kolom penyimpanan data biner foto tentang saya, tipe longblob.
     * about_image_mime : Kolom tipe format berkas foto tentang saya, tipe varchar(50).
